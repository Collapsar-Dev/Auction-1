# Аукцион тип 1 — дома и квартиры в Армении

Первая версия сайта по PRD «Аукцион тип 1» (1 нояб. 2026). Закрытый аукцион одной ставки: каждый участник делает **одну** ставку выше начальной цены и ничего не знает о чужих; в момент окончания все ставки открываются сразу и для всех, побеждает самая высокая (при равенстве — пришедшая раньше).

- **Сайт** — Next.js 15 (TypeScript), три языка (hy / ru / en), адаптивная вёрстка — `apps/web`
- **Сервер** — NestJS 10 (TypeScript), REST — `apps/api`
- **База** — PostgreSQL 16, суммы в драмах (`bigint`), время в UTC (`timestamptz`), на сайте — ереванское
- **Внешние сервисы** (банк ArCa, KYC, SMS, email, S3, KMS) — за интерфейсами, сейчас подключены фейковые адаптеры с песочницами (шаг P-1)

## Быстрый старт

Нужны **Node.js 20+** и **PostgreSQL 16**.

```bash
npm install
```

Создать базы `auction` и `auction_test` (пользователь `auction` / пароль `auction`) — один из вариантов:

```bash
npm run db:create
```

```bash
docker compose up -d db
```

Загрузить демо-данные (полностью очищает базу):

```bash
npm run seed
```

Запустить API (:4000) и сайт (:3000):

```bash
npm run dev
```

Открыть http://localhost:3000. Страница инструментов тестировщика — http://localhost:3000/dev.

Всё в Docker одной командой (не проверялось в этой среде — там нет Docker-демона):

```bash
docker compose up --build
```

```bash
docker compose exec api npm run seed
```

## Что попробовать

1. **Вскрытие в реальном времени.** Лот «Кентрон» (#1) заканчивается через 15 минут после `npm run seed`. Войдите Лилит, поставьте (подтверждение SMS-кодом, сумма прописью, квитанция с контрольным кодом). Не хотите ждать — на `/dev` «Конец через N с» для лота 1. В момент конца карточка показывает «Ставки закрыты…», через пару секунд — таблица всех ставок для всех, «Это вы», письма в `/dev`.
2. **Тайна ставок.** Пока лот идёт, ни гость, ни продавец (Анна), ни администратор не видят ни сумм, ни числа ставок. В базе сумма лежит только в зашифрованном виде.
3. **Полный путь новичка (Нарек).** Кабинет → email (ссылка подтверждения — на экране и в `/dev`) → «Пройти проверку» → песочница KYC → «Карты» → песочница банка → «Годовой доступ» → карточка лота → депозит → ставка.
4. **Продавец.** «Продать» → мастер из 5 шагов (в dev-режиме есть кнопка «добавить 10 демо-фото») → отправка на модерацию → вход админом → «Модерация» → одобрить. Время начала раньше чем через 24 ч после одобрения → лот вернётся с предложением сдвинуть время.
5. **Сделка.** Гор → «Арабкир» → «Перейти к сделке» → «Подтверждаю» → контакты продавца и список документов. Для «Давташена» загрузите выписку → админ → «Сделки» → «Продано» → депозит освобождается, с карты Карена списывается комиссия.
6. **Сроки.** На `/dev` «Часы сервера +49 ч» → неподтверждённая сделка «Арабкир» станет «не состоялась», депозит Гора — «спорный» (решение — в админке «Депозиты»), Гору — блокировка ставок на 30 дней. Кнопка «Сброс» возвращает часы.
7. **Новое в v0.2.** На карточке лота: подробное описание, фото по комнатам (фасад, гостиная, кухня, спальни, санузел, вид, планировка), блок «Документы проверены» и «Независимая оценка» с отчётом. В итогах — ID участника у каждой ставки и сообщение о втором шансе: проверьте Гором («Арабкир») — «Отказаться» → лот перейдёт Араму со 2-го места.
8. **Админка.** Модерация, лоты, пользователи (блокировка, бесплатный доступ на пилот), депозиты, сделки, риски (сигналы S-1…S-6), подтверждение средств, блокировки, споры (сверка контрольного кода), сбои, статусы писем, настройки правил, тарифы, журнал.

## Важные решения

Подробно — в [docs/ADR-001.md](docs/ADR-001.md). Кратко:

- **Защита ставок (7.4).** При одобрении лота создаётся пара ключей RSA-OAEP; закрытый ключ хранится только «обёрнутым» фейковым KMS, который отказывается разворачивать его до `closes_at`. Сумма шифруется сразу при приёме. Контрольный код = SHA-256(сумма + соль + id ставки); после вскрытия соль публикуется, и любой может проверить код прямо на карточке лота.
- **Фоновые задачи** — один цикл-сторож в процессе API (каждые 2 с) вместо Redis + BullMQ; все задачи идемпотентны, вскрытие — одна транзакция.
- **Таймер** — опрос API и сверка со временем сервера вместо WebSocket.
- **R-06 строже 7.4.4.** Сотрудники до итога не видят даже числа ставок.
- **v0.2:** после итога показываются ID участников; отказ победителя в течение 5 дней → лот 2-му месту; оценка объекта и чек-лист модератора (см. ADR-001).
